# Crawler CLI

Консольная программа, которая обходит сайты и сохраняет дерево найденных страниц в JSON.

## Что нужно

Установленный Go. Нужная версия указана в файле `go.mod`.

Проверить, что Go установлен:

```bash
go version
```

## Сборка

```bash
git clone https://github.com/alxtchshv/crawler-cli.git
cd crawler-cli
go build -o crawler ./cmd
```

После этого в папке появится исполняемый файл `crawler`.

## Запуск

```bash
./crawler --urls https://example.com --depth 2
```

Пример со всеми параметрами:

```bash
./crawler \
  --urls https://example.com,https://quotes.toscrape.com \
  --depth 3 \
  --workers 10 \
  --timeout 2m \
  --request-timeout 10s \
  --output result.json \
  --log crawler.log
```

## Параметры

| Параметр | Что означает | По умолчанию |
|---|---|---|
| `--urls` | Стартовые адреса через запятую. Обязательный | — |
| `--depth` | Насколько глубоко переходить по ссылкам. `0` — только стартовые страницы | `1` |
| `--workers` | Сколько страниц скачивать одновременно (от 1 до 10) | `10` |
| `--timeout` | Сколько времени даётся на весь обход, например `30s`, `2m` | `2m` |
| `--request-timeout` | Сколько ждать ответа от одной страницы | `5s` |
| `--output` | Файл, куда сохранить результат | `output.json` |
| `--log` | Файл, куда записывать ход работы и ошибки | `crawler.log` |

Список всех параметров можно посмотреть командой:

```bash
./crawler --help
```

## Что получится

- `output.json` — дерево страниц: адрес, заголовок и вложенные страницы.
- `crawler.log` — по строке на каждую страницу: `OK`, если она скачана, или `FAIL` с причиной, если пропущена.

## Как остановить

- Обход закончится сам, когда все страницы будут пройдены или истечёт `--timeout`.
- `Ctrl+C` — остановить досрочно. То, что уже успели собрать, всё равно сохранится в файл.
- Повторный `Ctrl+C` — завершить программу сразу.

## Тесты

Запустить все тесты:

```bash
go test ./...
```

Запустить с проверкой на гонки данных между горутинами:

```bash
go test -race ./...
```

Посмотреть подробно, какие проверки прошли:

```bash
go test -v ./...
```

Запустить тесты только одной части программы, например обхода:

```bash
go test -v ./internal/crawler
```

Тесты не ходят в интернет: сайты для проверок подменяются локальным сервером и заготовленными страницами.
